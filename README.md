# Milo Move Library

Collection of moves from Dance Central games for use with [Boomy](https://github.com/NORXND/Boomy)

## Content

| Origin                         | Songs | Total Moves |
| ------------------------------ | ----- | ----------- |
| Dance Central 1                | 32    | 884         |
| Dance Central 1 (DLCs)         | 31    | 815         |
| Dance Central 2                | 44    | 1318        |
| Dance Central 2 (DLCs)         | 31    | 1134        |
| Dance Central 3                | 46    | 1765        |
| Dance Central 3 (DLCs)         | 21    | 865         |
| Dance Central Spotlight        | 10    | 377         |
| Dance Central Spotlight (DLCs) | 0     | 0           |

In total 7158 moves in 215 songs.
Dance Central (2019) songs will probably never get ported due to incompatibility.

The library also contains all 1315 barks from every game available in all languages supported by DC3.
